How I work in the AI era

1A ready ticket, before any code

AI can automate delivery only when the ticket is clear. Vague requirements, missing information, unclear acceptance criteria and missing design links stop it. So the first step is a team effort: product owner, requirements engineer, software architect, developers, QA and project manager prepare the ticket together.

  • Tickets are written as specifications in SpecKit, used by requirements engineers, developers and AI agents.
  • AI agents draft the specifications and check them against rules and skills our team built for its own projects.
  • Every project is different, but the workflow stays predictable and the same every time.

Our job is to write those rules and skills, so the agents can do the rest.

2From ticket to pull request

Once a ticket is ready, a developer starts one workflow and reviews the pull request at the end. Everything in between is automated.

I built it as a set of Claude Code plugins, each with one job:

  • agentic-core: works on any platform. It takes a ticket to a pull request in 15 fixed stages, with three review gates, and stops for a person whenever the decision is theirs.
  • agentic-eds: the pack for Adobe Edge Delivery Services.
  • Swappable providers for Jira, GitHub, Figma and Playwright.
